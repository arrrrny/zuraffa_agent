## 5. GOTCHAS — Hard-Won Lessons

1. **`/workspace/` path contamination in pubspec_overrides.yaml** — both zuraffa and zuraffa_agent had stale Daytona sandbox paths. Always check pubspec_overrides.yaml before running zfa in local dev.
2. **`dart:io` purity gate**: zfa-generated code (execution_env, hive_session_store, etc.) legitimately uses dart:io as interface-backed adapters — the gate now uses an explicit allowlist, not filename heuristics.
3. **Branch numbering was a mess** — specs/001-state-and-sessions/spec.md was stranded in specs/002-state-and-sessions/; plan.md lost entirely. Completed rename (002→001) and restored plan.md from git history.
4. **Gate_patch false positive**: `grep -qiE 'CRITICAL|BLOCKER'` matched the severity legend header. Fixed to `^#### .*🔴`.
5. **Bash cwd resets to `/Users/ahmettok/Developer/zik_zak` every call** — always cd or use git -C.
6. **`nohup ... &` + `rm -f` in one line**: backgrounding footgun — separate the two.
7. **Zorphy generator nullable cast syntax**: `(String?)` is invalid in Dart expression context; must use postfix `as String?` instead. Prefix `(Type)(expr)` only works for non-nullable types.
8. **`implements DateTime` requires noSuchMethod**: abstract classes can't be const; concrete classes need all members or noSuchMethod. The `_DefaultDateTime` sentinel uses noSuchMethod returning null.
9. **tasks.md from manual run is poison for zfa-only runs**: the restored plan/tasks reference old-API constructs (AgentSession, ContentBlock, etc.) — implement agent faithfully implements what it reads, creating contamination files. Must rewrite before any zfa-only implement run.
10. **Implement agent writes barrel + tests against old APIs despite prompt**: the prompt says "NEVER hand-write generated-surface code" but tasks.md overrides it. Fix tasks.md first.
