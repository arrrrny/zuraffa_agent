## 5. GOTCHAs — hard-won lessons (CRITICAL)

### GOTCHA 1: zfa entity create doesn't support sealed hierarchies
- `zfa entity create` only creates flat entities. No `--sealed` or `--extends` flag.
- **BUT**: zorphy ALREADY supports sealed classes via `explicitSubTypes` annotation parameter.
- **Pattern**: Write source file manually with `@Zorphy(explicitSubTypes: [$SubA, $SubB])` on base class, then `@Zorphy()` on subtypes with `implements $$BaseClass`.
- **Example**: See `/Users/ahmettok/Developer/zuraffa_agent/lib/src/domain/entities/engine_event/engine_event.dart`
- **Golden reference**: `/Users/ahmettok/Developer/zorphy/zorphy/example/lib/src/domain/entities/shape/shape.dart`

### GOTCHA 2: zfa entity create doesn't recognize Duration type
- `Duration` is not a recognized field type. Use `int` for milliseconds instead.
- `zfa entity create -n StopPolicy --field wallClockTimeoutMs:int`

### GOTCHA 3: zfa entity create may not overwrite existing files
- If a file already exists (from previous session), `zfa entity create` may not overwrite it.
- Always verify the generated source file matches expectations after creation.

### GOTCHA 4: Working directory matters for zfa and dart analyze
- `zfa entity create` creates files relative to CWD. Must be in zuraffa_agent, not zik_zak.
- `dart analyze` resolves packages based on CWD. Always run from zuraffa_agent.
- I accidentally created engine_event in zik_zak first, then cleaned it up.

### GOTCHA 5: NEVER run flutter clean
- AGENTS.md hard rule. SPM deps take 20-30 min to re-resolve on Intel Mac.

### GOTCHA 6: Zorphy 2.0.1 code generation regressions (THE BIG ONE)
- **Missing `as Type` casts in patchWith**: Generator source HAS `as ${f.type}` but output doesn't include it.
- **toJsonLean returns dynamic**: Old pattern was `_sanitizeJson(data); return data;` (calls without returning). New pattern is `return _sanitizeJson(data);` (returns dynamic).
- **This affects ALL entities**, not just new ones. Old entities (chat_message) were generated by earlier zorphy and are clean.
