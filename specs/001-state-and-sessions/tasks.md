# Tasks: State & Sessions (zfa-only)

**Input**: Design documents from `/specs/001-state-and-sessions/`

**Prerequisites**: `plan.md`, `spec.md`

**⛔ CONSTITUTION I + IX + X MANDATE**: ALL scaffolding, entities, tests, and architecture
are generated by zfa CLI. Hand-written code is permitted ONLY for engine-core integration
glue (session tree operations, compaction orchestration) and ONLY when it references
zfa-generated types. NEVER reference old manual-run types (AgentSession, ContentBlock,
UsageEntry, UsageLedger, AgentMessage, HeuristicSummarizer, etc.). All generated
and hand-written files must pass `dart analyze` = No issues found (Article X).

**Generated entity names** (from `zfa entity create`): `ArtifactRef`, `BranchSummaryEntry`,
`CompactionEntry`, `CompactionSummary`, `CustomEntry`, `LabelEntry`, `Model`,
`ModelChangeEntry`, `ThinkingLevelChangeEntry`, `ToolInvocationRecord`, `TurnRecord`,
`UsageLedgerEntry`.

**ZFA commands for this spec**:
```
zfa entity create -n <Name> --field <field>:<type> --field ...     # create entity
zfa make <Name> --preset=crud --methods=get,getList,...            # generate architecture
zfa make <Name> --test                                             # generate test scaffold
zfa mock data <Name> --force                                       # generate mock data
zfa build                                                          # run codegen
```

## Format: `[ID] [P?] [Story] Description`

- **[P]**: Can run in parallel (different files, no dependencies)
- **[Story]**: Which user story this task belongs to (`[US1]`, `[US2]`, `[US3]`, `[US4]`)
- `dart analyze` must be run after EVERY task and must report **No issues found**
