# Data Model: State & Sessions

**Feature**: `001-state-and-sessions`  
**Date**: 2026-08-18  
**Spec**: [spec.md](spec.md)

## 1. Entity Overview

The state and session domain consists of immutable tree entries, multimodal messages, structured records for turns and tool calls, accounting projections, and compaction summaries.

```text
SessionTreeEntry (sealed)
├── MessageEntry ──────────────> AgentMessage (sealed)
│                                 ├── UserMessage
│                                 ├── AssistantMessage ──> ContentBlock (sealed)
│                                 ├── ToolResultMessage     ├── TextBlock
│                                 └── CustomMessage         ├── ImageBlock
├── TurnRecord                                              ├── AudioBlock
├── ToolInvocationRecord                                    ├── DocumentBlock
├── UsageLedgerEntry                                        ├── ToolCallBlock
├── CompactionEntry ───────────> CompactionSummary          └── ThinkingBlock
│                                 └── ArtifactRef
├── ThinkingLevelChangeEntry
├── ModelChangeEntry
├── BranchSummaryEntry
├── LabelEntry
└── CustomEntry
```

## 2. Core Entities & Value Objects

### 2.1 `SessionTreeEntry` (Sealed Base Entity)
Base node in the append-only session tree.
- **Fields**:
  - `id`: `String` (monotonic unique entry identifier, e.g., `e_1723996800000000_1`)
  - `parentId`: `String?` (identifier of ancestor node; `null` or empty string for root)
  - `timestamp`: `DateTime` (UTC timestamp when entry was recorded)
- **Subclasses**:
  - `MessageEntry`: Wraps an `AgentMessage` with its conversation role (`user`, `assistant`, `toolResult`, `custom`).
  - `TurnRecord`: Marks the boundary and metadata of an engine execution turn.
  - `ToolInvocationRecord`: Captures a specific tool invocation, its parameters, execution timing, and artifact references.
  - `UsageLedgerEntry`: Records token usage metrics associated with an LLM call.
  - `CompactionEntry`: Records a selective compaction event with summary and context pointers.
  - `ThinkingLevelChangeEntry`: Represents a change in agent thinking mode/budget (`thinkingLevel`).
  - `ModelChangeEntry`: Records a model switch (`modelId`, `provider`).
  - `BranchSummaryEntry`: Captures branch-level intent or summary notes.
  - `LabelEntry`: User- or system-defined tag attached to a point in history.
  - `CustomEntry`: Extensible custom data payload.

### 2.2 `AgentMessage` & `ContentBlock` (Sealed Hierarchies)
Typed multimodal message system.
- `AgentMessage` (sealed):
  - `UserMessage`: User prompt containing a list of `ContentBlock` items.
  - `AssistantMessage`: Assistant output containing text, tool calls, and thinking blocks.
  - `ToolResultMessage`: Tool execution outcome linked to a `toolCallId` and `toolName`.
  - `CustomMessage`: Custom message type for extension scenarios.
- `ContentBlock` (sealed):
  - `TextBlock`: Plain text string.
  - `ImageBlock`: Base64 or binary image payload with `mimeType`.
  - `AudioBlock`: Audio data payload with `mimeType` and duration metadata.
  - `DocumentBlock`: PDF or rich document payload with `mimeType` and title.
  - `ToolCallBlock`: Tool call request with `id`, `name`, and typed `arguments` map.
  - `ThinkingBlock`: Chain-of-thought or reasoning trace with `thinking` text.

### 2.3 `TurnRecord`
Encapsulates an atomic engine loop turn.
- **Fields**:
  - `id`: `String`
  - `parentId`: `String?`
  - `timestamp`: `DateTime`
  - `turnNumber`: `int` (1-based index)
  - `messageEntryIds`: `List<String>` (IDs of messages contained in this turn)
  - `toolInvocationEntryIds`: `List<String>` (IDs of tool invocations executed in this turn)
  - `stopReason`: `StopReason` (`endTurn`, `maxTokens`, `stopSequence`, `toolUse`, `error`, `cancelled`)
  - `startedAt`: `DateTime`
  - `endedAt`: `DateTime`
  - `durationMs`: `int` (derived or explicit duration in milliseconds)
- **Validation**:
  - `turnNumber >= 1`
  - `messageEntryIds` must reference valid entries on the active branch ancestry.

### 2.4 `ToolInvocationRecord`
Granular record of an individual tool call.
- **Fields**:
  - `id`: `String`
  - `parentId`: `String?`
  - `timestamp`: `DateTime`
  - `toolCallId`: `String` (ID matched to `ToolCallBlock.id`)
  - `toolName`: `String`
  - `arguments`: `Map<String, Object?>` (validated typed parameters)
  - `resultEntryId`: `String?` (nullable while tool is in flight; points to `ToolResultMessage` entry on completion)
  - `isError`: `bool`
  - `durationMs`: `int`
  - `artifactRefs`: `List<ArtifactRef>` (pointers to disk, memory, or external artifacts generated by the tool)

### 2.5 `UsageLedgerEntry` & `UsageLedger` (Projection)
Granular accounting for LLM token usage and budget enforcement.
- `UsageLedgerEntry`:
  - `id`: `String`
  - `parentId`: `String?`
  - `timestamp`: `DateTime`
  - `callId`: `String`
  - `turnNumber`: `int`
  - `model`: `Model` (provider, model ID, context window)
  - `inputTokens`: `int`
  - `outputTokens`: `int`
  - `cacheReadTokens`: `int` (default 0)
  - `cacheWriteTokens`: `int` (default 0)
- `UsageLedger` (Read Projection):
  - `totalInputTokens`: Sum of `inputTokens`.
  - `totalOutputTokens`: Sum of `outputTokens`.
  - `totalTokens`: `totalInputTokens + totalOutputTokens`.
  - `byTurn(int turnNumber)`: Sub-ledger for a specific turn.
  - `byModel(String modelId)`: Sub-ledger for a specific model.

### 2.6 `CompactionEntry`, `CompactionSummary` & `ArtifactRef`
Selective compaction structures.
- `CompactionSummary`:
  - `decisions`: `List<String>` (surviving key decisions)
  - `toolNames`: `List<String>` (tools executed in the compacted range)
  - `keyResults`: `List<String>` (essential outputs and return values)
  - `planState`: `String?` (current high-level plan or next steps)
  - `artifacts`: `List<ArtifactRef>` (pointers to preserved full outputs)
- `ArtifactRef`:
  - `kind`: `String` (e.g., `tool-output`, `file`, `diff`)
  - `id`: `String` (resolvable identifier)
  - `uri`: `String?` (optional URI or file path)
- `CompactionEntry`:
  - `id`: `String`
  - `parentId`: `String?`
  - `timestamp`: `DateTime`
  - `summary`: `CompactionSummary`
  - `firstKeptEntryId`: `String` (ID of the earliest uncompacted entry on the branch)
  - `tokensBefore`: `int`
  - `tokensAfter`: `int`

## 3. Session Tree Lifecycle & State Transitions

```text
[Session Created] ──> Root Entry (e0)
                           │
                      [Append e1]
                           │
                      [Append e2 (Leaf A)]
                        /            \
        [Fork at e1]   /              \   [Fork at e2]
                      v                v
                 Branch B (e3)    Branch C (e4)
                      │                │
                 [Append e5]      [Append e6]
```

- **Ancestry Sharing**: Branch B and Branch C share common ancestor entries (`e0`, `e1`) without duplicating storage records.
- **Context Construction (`buildContext`)**: Reverses ancestry chain from active leaf `L` up to root `e0`, applying compaction boundaries if present.
- **Pruning (`deleteBranch`)**: Removes leaf-only nodes upwards until encountering a node that has other surviving child entries in the session tree.
